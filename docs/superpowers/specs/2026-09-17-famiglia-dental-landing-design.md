## 1. Загальний огляд та цілі проєкту

Створення веб-сайту для авторської сімейної стоматологічної клініки **Famiglia** у Львові. Засновниця — лікар із 15-річним стажем **Тетяна Бибіс** (`@tetiana_bybis`). 

### Ключові цілі:
1. **Трансляція бренду та довіри:** Відображення затишної, теплої та безпечної атмосфери («стоматологія без страху і болю») у палітрі бежевих, молочних та кавових тонів відповідно до Instagram-профілю клініки.
2. **Презентація ключових напрямків:** Естетична реставрація, ортодонтія (брекети та елайнери), дитяча стоматологія, терапія під мікроскопом, імплантація та гігієна.
3. **Висока конверсія заявок:** Зручна форма попереднього запису з вибором послуги, бажаної дати та часу доби.
4. **Миттєві сповіщення адміністраторів:** Автоматична доставка нових заявок у робочий Telegram-чат клініки через безпечний серверний роут Next.js.
5. **Двомовність (UA / EN):** Забезпечення комфортного досвіду як для мешканців Львова, так і для іноземних пацієнтів та експатів.

---

## 2. Технологічний стек

* **Frontend & Backend Framework:** Next.js 14+ (App Router, TypeScript).
* **Стилізація:** Tailwind CSS з кастомною системою токенів кольорів і типографіки.
* **Іконки:** Lucide Icons (`lucide-react`).
* **Локалізація:** Легкий контекстний i18n-провайдер із підтримкою мовних файлів `ua.json` та `en.json`.
* **Серверний API-роут:** `/api/appointment` (Next.js route handler) із валідацією полів та інтеграцією з Telegram Bot API.
* **Безпека:** Змінні середовища `TELEGRAM_BOT_TOKEN` та `TELEGRAM_CHAT_ID` зберігаються виключно на сервері (`.env.local`).

## 5. Інтеграція з Telegram Bot API

### Ендпоінт: `POST /api/appointment`

#### Схема вхідних даних:
```json
{
  "name": "Оксана Мельник",
  "phone": "+380961112233",
  "service": "Ортодонтія (елайнери)",
  "date": "2026-09-25",
  "timeSlot": "Ранок (10:00–13:00)",
  "comment": "Потрібна консультація щодо прикусу",
  "locale": "ua"
}
```

#### Повідомлення в Telegram-чат:
```html
🦷 <b>Новий запис на прийом: Famiglia</b>

👤 <b>Пацієнт:</b> Оксана Мельник
📞 <b>Телефон:</b> +380961112233
🩺 <b>Послуга:</b> Ортодонтія (елайнери)
📅 <b>Бажана дата:</b> 2026-09-25
⏰ <b>Зручний час:</b> Ранок (10:00–13:00)
💬 <b>Коментар:</b> Потрібна консультація щодо прикусу
🌐 <b>Мова:</b> UA
🕒 <b>Час заявки:</b> 17.09.2026 12:45
```

#### Режим Graceful Fallback:
* Якщо `TELEGRAM_BOT_TOKEN` або `TELEGRAM_CHAT_ID` не задані (локальне тестування), сервер логує повідомлення у консоль і повертає `status: 200` з повідомленням `mode: "mock"`, забезпечуючи безперебійне тестування користувацького інтерфейсу.
