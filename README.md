# Стоматологічна клініка «Famiglia» (м. Львів) — Офіційний веб-сайт

Преміальний, конверсійний та двомовний (UA / EN) сайт-лендинг для авторської стоматологічної клініки **Famiglia** у Львові (вул. Бойківська, 2).

Проєкт розроблено на основі бренд-платформи та візуального стилю Instagram-профілю [@famiglia_2022](https://www.instagram.com/famiglia_2022) у теплій бежево-кавовій та кремовій палітрі (затишок, комфорт і довіра без «лікарняного холоду»).

---

## 🌟 Ключові особливості

- **Двомовність (UA / EN):** Миттєве перемикання мов без перезавантаження сторінки завдяки вбудованій контекстній системі локалізації.
- **Розширена інтерактивна форма запису:**
  - Валідація номеру телефону (+380...)
  - Вибір бажаної послуги
  - Календарний вибір дати (з обмеженням від сьогоднішнього дня)
  - Вибір зручного часу доби (Ранок / День / Вечір)
  - Додатковий коментар пацієнта
- **Миттєві сповіщення у Telegram-бот:**
  - Заявки надсилаються прямо в робочий чат адміністраторів клініки
  - Гарне HTML-форматування з emoji та всіма даними пацієнта
  - Безпечний серверний API-роут (`/api/appointment`)
  - **Graceful Fallback (Mock Mode):** якщо токени бота ще не налаштовані, сайт не падає з помилкою, а логує заявку в консоль і показує пацієнту успішне підтвердження.
- **Інтерактивна галерея «До / Після»:**
  - Порівняння результатів реставрації, вирівнювання елайнерами та відбілювання за допомогою інтерактивного повзунка з підтримкою сенсорних екранів.
- **Блок засновниці Тетяни Бибіс (`@tetiana_bybis`):**
  - 15+ років клінічного досвіду, особистий бренд та принципи безболісного сімейного лікування.
- **Дитяча стоматологія 🧸:**
  - Адаптаційні візити та лікування без сліз і страху.
- **Дизайн-система (UI/UX Pro Max):**
  - Кольори: `brand-dark` (#2D241E), `brand-gold` (#C5A880), `brand-beige` (#F6F2EA), `brand-bg` (#FBF9F5).
  - Адаптивність для всіх екранів (Mobile 375px, Tablet 768px, Desktop 1024px+).

## 🚀 Швидкий старт локально

### 1. Встановлення залежностей
```bash
npm install
```

### 2. Запуск тестів
```bash
npm test
```

### 3. Запуск сервера розробки
```bash
npm run dev
```
Відкрийте браузер за адресою: [http://localhost:3000](http://localhost:3000)

### 4. Збірка для продакшну
```bash
npm run build
npm start
```

## 🤖 Підключення Telegram-бота для сповіщень

1. Створіть файл `.env.local` у кореневій директорії проєкту (скопіюйте з `.env.example`):
   ```bash
   cp .env.example .env.local
   ```
2. **Отримайте токен бота:**
   - Відкрийте Telegram і напишіть офіційному боту [@BotFather](https://t.me/BotFather).
   - Надішліть команду `/newbot`, оберіть назву (наприклад, `Famiglia Dental Bot`) та username.
   - Скопіюйте отриманий API Token і вставте у `TELEGRAM_BOT_TOKEN`.
3. **Отримайте Chat ID для сповіщень:**
   - Напишіть боту [@userinfobot](https://t.me/userinfobot) або додайте створеного бота у групу адміністраторів клініки та перевірте Chat ID через [@RawDataBot](https://t.me/RawDataBot).
   - Вставте отриманий числовий ID у `TELEGRAM_CHAT_ID`.
4. Перезапустіть сервер — тепер усі заявки з сайту надходитимуть у Telegram у режимі реального часу!
